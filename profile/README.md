# The open building blocks for Quran applications.

Quran.ws provides the open building blocks behind reliable Quran experiences:

- **Source-verified text** — traceable to its printed edition
- **Accurate Mushaf pages** — faithful to the line and the page
- **Reusable visual assets** — ready to drop into any interface
- **Qiraat-aware mappings** — ayah numbering differs between them
- **Tajweed annotations** — marked on the text itself
- **Cross-platform rendering tools** — one text, every platform

Use one building block on its own, or combine them into a complete Quran application.

# مكوّنات مفتوحة لبناء تطبيقات القرآن.

يوفر Quran.ws المكوّنات المفتوحة لبناء تجارب قرآنية موثوقة:

- **نصّ موثّق المصدر** — يُعزى إلى طبعته المطبوعة
- **صفحات مصحف دقيقة** — مطابقة للسطر والصفحة
- **أصول بصرية قابلة لإعادة الاستخدام** — جاهزة لأي واجهة
- **خرائط تراعي اختلاف عدّ الآي** — فالعدّ يختلف بينها
- **بيانات للتجويد** — معلَّمة على النصّ نفسه
- **أدوات عرض تعمل عبر المنصات**

استخدم المكوّن الذي تحتاجه وحده، أو اجمع عدة مكوّنات لبناء تجربة قرآنية متكاملة.

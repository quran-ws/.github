# المساهمة في Quran.ws

كل مستودع في هذه المنظمة مفتوح للمسائل (`Issues`) وطلبات الدمج (`PRs`). وتشرح صفحة [كيف تساهم](https://quran.ws/docs/contribute/) أين يذهب كل نوع من التغيير وما يحتاجه طلب الدمج ليُدمج.

- **قاعدة أو مصطلح أو صفحة من الأدلة**: مستودع [quran-ws/docs](https://github.com/quran-ws/docs). ابدأ بـ`Issue` بأحد قوالبه الثلاثة، أما تصحيح فقرة واحدة فأرسله في `PR` مباشرة.
- **بيانات أو كود في أحد المكوّنات**: مستودع ذلك المكوّن. يذكر ملف `README` فيه بنية المستودع والفحوص التي يجب أن تبقى ناجحة.
- **خطأ في الموقع**: `Issue` في [quran-ws/docs](https://github.com/quran-ws/docs/issues/new/choose) مع رابط الصفحة.

ولا يعدّل أي `PR` النص القرآني بيده؛ فالخلل في النص خلل في مصدره، ويُصحَّح هناك بمراجعة ثانية، وفق [دليل النص القرآني](https://quran.ws/docs/guidelines/ar/quranic-text/).

# Contributing to Quran.ws

Every repository in this organisation takes issues and pull requests. [How to contribute](https://quran.ws/docs/contribute/) says where each kind of change goes and what a pull request needs to be merged.

- **A rule, a term, or a guideline page**: [quran-ws/docs](https://github.com/quran-ws/docs). Open an issue first, with one of its three forms; a one-paragraph fix goes straight to a pull request.
- **Data or code in a block**: that block's repository. Its README maps the repository and names the checks that must stay green.
- **A mistake on the site**: an issue on [quran-ws/docs](https://github.com/quran-ws/docs/issues/new/choose) with the page's URL.

No pull request edits the Qurʾānic text by hand. A defect in the text is a defect in its source, fixed there with a second reviewer, under the [Qurʾān text guideline](https://quran.ws/docs/guidelines/quranic-text/).
